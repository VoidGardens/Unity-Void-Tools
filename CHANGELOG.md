## [1.0.0] - 2026-08-09
### First Release
- Camel Case Renamer. Renames selected assets using camel case
- Clean Name Copie. Adds button to copy clear GO name
- Collection Object Mover. Pin GOs where to move other GOs
- Copy Full Path. Copy full asset path without opening Window's Explorer
- Prefaber. Prepare an object for prefabing (removes all components except for mesh filter and mesh renderer, creates parent GO, uses camel case)
- Quick Screenshot. Makes quick screenshots of Game window
- Select By Mayerial. Select objects within scene with same material or texture
- Transform Group Game Object. Bulk GO transofrm modifier
